# N3, этап 1: отношение дисперсий на перпах (механизм возврата к средней для сетки)

Раздел дизайна: `n-family-experiment-designs-1105-spec.md` §5 (86dc8c9). Коммитится до загрузки и до расчётов. Этап 2 (книга сеток) — только при GO, отдельной записью в этой же спеке.

Инварианты: TH-03, TH-04, TH-05, TH-08, TH-10, TH-11, TH-12. Семейство N3, α = 0.05, 5 главных горизонтов, значит α = 0.01 на горизонт.

## 1. Что фиксируется до данных
Дизайн задаёт статистику, горизонты, разбивки, окна и GO. Ниже — то, что он оставил агенту.

**Вселенная на месяц.** Дизайн считает VR «по каждому символу в каждом календарном месяце» и задаёт вселенную на день d. Состав месяца = топ-20 на первый день месяца и больше не меняется. Это использует только данные до начала месяца.
Поздний вход в топ не учитывается внутри месяца, это честно по времени и упрощает пул.

**Ранг.** Сумма `quote_volume` 1d-баров за [d−30, d−1], ≥ 25 дней с данными из 30, возраст ≥ 30 дней (первый день торгов ≤ d − 30). Источник — архив 1d по ВСЕМ USDT-перпам архива, а не `perp_history`. Причина: `perp_history` содержит только монеты, бывшие в топ-100 спота, и в нём могут отсутствовать крупные перпы без спота на Binance. Это ловушка выживания и выбора, которую дизайн требует закрыть (§1.5).

**Исключены из ранга:** базы из `trading_universe.STABLE_BASES` и `archive_bh.OLD_PEGGED` (`USDCUSDT`-перп и подобные: дисперсия привязанного актива — не тот механизм). Индексные перпы (`DEFIUSDT`, `BTCDOMUSDT`, `FOOTBALLUSDT`, `BLUEBIRDUSDT`) остаются. Символы с не-ASCII именем включаются, URL кодируется.

**Данные 15m.** 2023–2025: `perp_history`. 2020-01..2022-12: `history_bh/perp`, плюс 8 символов, которых там нет: `BLUEBIRDUSDT, BNXUSDT, BTCDOMUSDT, DEFIUSDT, DOTECOUSDT, FOOTBALLUSDT, LUNA2USDT, TLMUSDT` (`archive_bh.fetch_extra`). Если символ из топ-20 какого-то месяца отсутствует в хранилище — докачать `data/futures/um/monthly/klines/<SYM>/15m/` в `runtime/usdc_n3/`, число таких символов записать. Символ `perp_history` ищется по `mapping.json`.

**Инвентарь.** 1d USDT-перпов ≤ 2025-12: 638 символов, 15 686 файлов, 27.5 МБ (листинг 2026-11-06). 8 символов 15m плюс недостающие из топ-20: оценка < 100 МБ. Всего меньше 2 ГБ, разрешение не требуется. Хранилище 1d: `runtime/usdt_1d/`. Месяцы позже 2025-12 не запрашиваются.

**Доходность.** log(c_t / c_{t−1}) только если оба бара существуют, идут подряд с шагом 15 минут и у обоих v > 0. Иначе интервал пропущен. Перекрывающаяся сумма длины q считается только по окнам, где все q доходностей есть.

**Символ-месяц** участвует, если есть ≥ 1 440 доходностей (половина месяца). Иначе он отбрасывается и считается. Делистинг посреди месяца: остаток считается, если порог выполнен.

**VR(q) Ло–Маккинли.** N — число доходностей, W — число полных окон, μ — их среднее.
- σ_a² = Σ(r − μ)² / (N − 1)
- m = q · W · (1 − q / N)
- σ_c²(q) = Σ_окна (S_q − qμ)² / m
- VR = σ_c² / σ_a²

Без пропусков W = N − q + 1, и это в точности формула Ло–Маккинли со смещённой поправкой. С пропусками это приближение; доля пропусков выводится в отчёт.

**z\*.** Устойчивая дисперсия θ(q) = Σ_{j=1}^{q−1} [2(q − j)/q]² δ_j, где δ_j = N · Σ (r_k − μ)² (r_{k−j} − μ)² / [Σ (r_k − μ)²]²; суммирование только по парам, где обе доходности есть. z\* = √N · (VR − 1) / √θ.

**Пул.** В месяце — равновзвешенное среднее (VR_s(q) − 1). Итог — среднее по месяцам. Интервал: блоковый бутстрап по месяцам, блок 3, B = 20 000, уровень 99% на главном горизонте, `n_common.ci`. Справочные q = 2, 192, 288 с тем же расчётом без веса в GO.

**Разбивки.**
- по году;
- терцили волатильности: внутри месяца символы делятся по σ 15m-доходностей за 30 дней до первого дня месяца, строго без данных месяца;
- BTC и ETH отдельно — их средние (VR − 1) по всем месяцам окна, где они в топ-20.

**Отскок бид-аск.** При половине спреда c смещение VR(q) − 1 ≈ −(2c²/σ_r²)(1 − 1/q). c берётся из `COST_CAL.json`: по live-таблице, размер 1 000 USDT, B1 для BTC и ETH, B2 для остальных; это издержка рыночной заявки от середины. Проверка: |смещение| / |измеренный эффект| < 10% на каждом главном горизонте, при c ×1 и справочно ×3. Для 2020–2022 спреды неизвестны, поэтому используется ×3. Если условие не выполнено при ×1, расчёт повторяется на mark price, как требует дизайн, и это пишется в журнал.

**Мощность** по §1.3 дизайна. Единица — месяц. δ = 0.02 по модулю, α = 0.01, мощность 0.80. σ — стандартное отклонение месячного пула на разведке; m = 3, ρ — автокорреляция лага 1 месячного пула на разведке, отрицательная ρ заменяется нулём. Доступно 30 месяцев (2020-07..2022-12). σ и ρ пишутся в журнал и коммитятся ДО взгляда на решающее окно. Если n_eff > 30 на всех соседних парах горизонтов, окно не открывается.

**GO** — как в дизайне, без изменений: на решающем окне два соседних главных горизонта с пулом < 0 и верхней границей 99% < 0, и знак отрицателен минимум в 4 годах из 6 (2020–2025) на обоих этих горизонтах. Иначе СТОП с записью «у сетки нет механизма на масштабах 1–24 ч». Вердикт словами §1.2 дизайна: «отклонена» только при верхней границе < δ по модулю, то есть если ни на одном горизонте эффект сильнее −0.02 не допускается интервалом: нижняя граница > −0.02.

**Журнал взглядов.** Перед решающим расчётом запись в `docs/audit/alpha_ledger.json` с датой из часов; маркер `N3_VR_BH_OPENED.json` ставится до чтения окна.

## 2. Тесты до кода
`trader/test_n_common.py` (общие помощники) и `trader/test_n3_vr.py`:
- случайное блуждание: среднее VR ≈ 1 при длине месяца, по всем горизонтам;
- AR(1) с ρ = −0.2: VR(2) ≈ 0.8;
- z\* на гетероскедастичном шуме: доля отказов на 5% близка к 5%; обычный z без поправки завышал бы её;
- пропуск убирает соседний интервал; бар с v = 0 считается пропуском;
- вселенная не использует день d и позже;
- терциль не использует данные месяца;
- GO: два соседних горизонта и годы; несоседние не проходят;
- порог 1 440 доходностей.
