# N4: фандинг и премия (G1, G2) на USDT- и USDC-перпах

Раздел дизайна: `n-family-experiment-designs-1105-spec.md` §6 (86dc8c9). Коммитится до загрузки и до расчётов. Прежний этап 0 (`funding-premium-g1g2-1105-spec.md`) дал G1 и G2 без положительного результата на другом коде; этот расчёт правила не наследует и правится только по дизайну.

Инварианты: TH-03, TH-04, TH-05, TH-08, TH-10, TH-11, TH-12. α семейства 0.05: G1 два кандидата по 0.0125, G2 два кандидата по 0.0125. 2026 закрыт.

## 1. Сверка с документацией Binance (записывается до кода, как требует дизайн)
Страница «Introduction to Binance Futures Funding Rates» (FAQ 360033525031, обновлена 2026-03-06; прочитана 2026-11-06):
- F = [P + clamp(I − P, −0.05%, +0.05%)] / (8 / N), N — интервал в часах;
- I = 0.01% за 8 часов (0.03% в день), для большинства символов;
- P — взвешенная премия по точкам каждые 5 с с весами 1, 2, …, n; для интервала 1 ч веса равны;
- потолок: ±2% для прочих, для списка символов ±0.75 × поддерживающая маржа; расчёт идёт с отклонением до 15 с.

**Расхождение с дизайном.** Дизайн пишет F̂ = P̄ + clamp(I − P̄, ±0.05%) и I = 0.01% × (интервал / 8 ч). Документация делит ВСЁ выражение на 8/N, а I в клампе остаётся 0.01%. При N = 8 формулы совпадают, при N = 4 или 1 нет. Дизайн велит сверить с документацией, поэтому принимается она:

**F̂ = [P̄ + clamp(0.01% − P̄, −0.05%, +0.05%)] · N / 8.**

Страница описывает текущую формулу; была ли она такой же в 2020–2023, по ней не видно. Поэтому точность прогноза (корреляция, совпадение знака) пишется в отчёт отдельно по N и по годам.

## 2. Что фиксируется до данных

**Вселенная:** топ-100 USDT-перпов на день начисления или бара, `n_common.Volumes`, база-пеги исключены. Так как ранг ≤ 100, корзины B4 здесь нет, и критерий дизайна «весь плюс только в B4» сработать не может. Он заменён отчётом по B1, B2, B3 без влияния на вердикт: B3 показывается как худшая корзина.

**Издержки на сторону:** USDT-M тейкер 0.050%, спот 0.100%, USDC-M тейкер 0.040%; проскальзывание B1 0, B2 0.6 б.п., B3 3.3 б.п., ранг на день сделки. Текущая сетка на всех окнах, это пишется в результате. BNB — чувствительность: 0.045%, 0.075%, 0.036%. Проскальзывание ×0, ×1, ×2.5.

**G1.**
- Метки начислений фактические. T округляется вниз до 15 минут (отклонение до 15 с); интервал N = (T − T_prev), округлённый до часа.
- Прогноз на T − 15 мин: P̄ по закрытиям баров премии, начатых не раньше T_prev и закрытых не позже T − 15 мин. Веса 1, 2, …, k, при N = 1 равные. Потолок ставки в прогнозе не применяется.
- Запасной прогноз (ставка предыдущего начисления) — если нет ни одного бара премии. Его доля в отчёте.
- Событие: T символа вселенной при |F̂| ≥ c, c ∈ {0.10%, 0.30%} за интервал.
- Сторона: F̂ > 0 — шорт, F̂ < 0 — лонг.
- Вход по закрытию бара, открытого в T − 30 мин; выход по закрытию бара, открытого в T. Нет точного бара — событие отбрасывается и считается.
- Фандинг = фактическая ставка, знак по стороне: если прогноз ошибся, сторона платит.
- Чистый доход = цена + фандинг − 2 × (тейкер + проскальзывание), б.п. номинала.

**Плацебо G1.** T' = T ± 2 ч, окно [T' − 15 мин, T' + 15 мин] не содержит начисления этого символа; при N = 1 плацебо нет. Условие |F̂| ≥ c и сторона считаются **в момент T' − 15 мин по премии текущего интервала к этому моменту**, а не берутся у события T: сдвиг назад с условием из будущего — это ловушка 1 (§1.9). Фандинга в плацебо нет. «Эффект начисления» = основное − плацебо, справочно.

**Мейкерский вход G1 (чувствительность).** Решение на T − 30 мин по премии к этому моменту, лимит по закрытию бара; исполнение при сквозном движении в следующем баре, иначе события нет; мейкер 0.020%, выход тейкером.

**USDC для G1 — справочно:** 15 монет N1-C, с 2024-01, тейкер 0.040%. Курс USDC/USDT за 30 минут удержания не учитывается: номинал в USDC и движение за 30 минут дают эффект второго порядка, это записано в `not_modelled`.

**G2.**
- Премия p_t — закрытие 15m-бара `premiumIndexKlines`. Вход при p_t > θ: 0.4% для рангов 1–20, 0.8% для 21–100, ранг на день бара.
- Спот: USDT-пара той же монеты, сопоставление `funding_store.perp_to_spot`, множитель учитывается. Медиана (перп × множитель / спот − 1) должна быть в пределах 0.5% (`funding_premium.pair_ok`), иначе пара не считается: урок STRAX и RAY. Отброшенные считаются.
- Исключаются бары первых 3 дней (72 ч) от запуска перпа (первый бар 1d) и от первого бара спота.
- Вход по закрытию бара t на обеих ногах; бара нет — событие отброшено и посчитано.
- Выход: первый бар после входа с p < θ/3, иначе бар t + 32 × 15 мин, по закрытию обеих ног. Нет бара выхода — событие отброшено и посчитано. Если перп кончился и символ больше не торгуется (делистинг): закрытие по последней цене без штрафа, причина `delisted`.
- На символ одна позиция; новый сигнал только после выхода.
- Фандинг: сумма фактических ставок в (закрытие бара входа, закрытие бара выхода], шорт получает ставку.
- USDC-вариант: те же монеты, премия и бары USDC-перпа, порог по рангу USDT-версии; вклад курса = номинал × (fx_конец − fx_начало) / fx_начало по минутному закрытию, заглядывания нет.

**USDC-кандидат G2 без решающего окна.** USDC-перпы появились в 2024-01, решающее окно 2020-07..2022-12 для них пусто. Он считается только на разведке 2024–2025 и получает «не проверяемо». Его α не передаётся другому кандидату.

**Плацебо G2:** для каждого события того же символа — бар с p ∈ [0, θ/2], равномерно среди таких баров окна (seed 29), те же правила выхода и издержки; условие только на текущем баре.

**Чувствительность G2:** вход на закрытии следующего бара, справочно, потому что этап 0 показал разницу между нулевой задержкой и 15 минутами.

**Главный показатель:** средний чистый доход на событие, б.п.; кластеры по дню; уровень 98.75%; B = 20 000; `n_common.cluster_ci`.

**Мощность.** σ, m, ρ (ICC по дню) с разведки. δ = 3 б.п. для G1 и 10 б.п. для G2, α = 0.0125, мощность 0.80. Записывается в журнал и коммитится до решающего окна. Доступно: число событий на 2020-07..2022-12, считается **только по премии, ставкам и объёму, без цен и без исходов**. Если доступно < n_eff, окно этого кандидата не открывается (§1.3 дизайна).

**Окна.** Разведка 2023-01-01..2025-12-31 (USDC с 2024-01). Решающее 2020-07-01..2022-12-31, один взгляд на G1 и один на G2, запись в `alpha_ledger.json`, маркеры `N4_G1_BH_OPENED.json`, `N4_G2_BH_OPENED.json` до чтения.

**Вердикт на решающем окне:** принята — нижняя граница > 0; отклонена — верхняя граница < δ или нижняя ≤ 0 (критерий «убить» дизайна); иначе не доказана. Для G2 ещё: доход только в дни листинга — убить; проверка, что фильтр 72 ч сработал, в отчёте (доля событий в первые 7 дней символа).

**Проверка хвоста (§0.6):** среднее без 5 лучших дней, доля 5 лучших символов; при доходе > 3σ издержек или Sharpe > 5 — разбор до вывода.
