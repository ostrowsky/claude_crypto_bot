## П-1. Калибровка движка выходов

Прежний движок (`_backtest_weak_exit_above_breakeven.replay`) вёл стоп от
максимума с шириной, зафиксированной по ATR на баре выхода, и исполнял выход
внутри бара ровно по стопу. Живой трейл (`monitor._compute_trail_buffer`) ведёт
стоп от **закрытия**: `stop = max(stop, close − max(k·ATR_now, floor·close))` на
каждом закрытом баре, выход — на закрытии, когда `close < stop`. Новый движок
`live_trail` повторяет живое правило без ужесточений (profit-lock, trend-hold,
EXIT_RL TIGHTEN).

Проверка — на 1 909 реальных выходах бота по ATR-трейлу (15m, 2026-03 … 09):

| | значение |
|---|---|
| бар выхода совпал ±1 | 1 088 из 1 909 (**57%**); медиана смещения 0, p75 +29 баров |
| pnl повтора − реальный, среднее | **+0.007%** (медиана −0.000%) |
| старый движок на тех же выходах | **+0.550%** |
| повтор выходит позже / раньше | 776 / 45 — живой стоп туже из-за ужесточений |

Итог: по **среднему** pnl новый движок несмещён (+0.007% против +0.550% у
старого), по **времени** выхода — нет: в 41% случаев живой стоп туже. Поэтому
новый движок годится для сравнения средних, но не для утверждений о моменте
выхода. Все прежние абсолютные вердикты старого движка по выходам завышены
примерно на +0.5% на сделку.

0.000 …)» уже прошёл price edge, daily_range и RSI. Ослабление: прогноз ровно 0

ranker_hard_veto, clone_guard, open_cluster_cap, correlation_guard,
late_impulse_rotation, bandit_skip; для ослабленного блока они не вычислялись,
