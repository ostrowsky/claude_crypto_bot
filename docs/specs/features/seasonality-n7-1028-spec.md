# N7 — внутридневная и недельная сезонность BTC/ETH: проверка верхней границей, предрегистрация

Дата: 2026-10-28. Источник: `trader-hypotheses-1028-spec.md`, N7. Офлайн, только трейн 2023-03-01..2025-12-31.

## 1. Идея проверки

Сезонное правило держит актив только в одном окне — час суток или день недели — и платит один круг издержек
за каждое окно. Если даже **лучшее задним числом** окно на трейне не окупает круг, никакое правило, выбранное
по трейну, не окупит его вне выборки. Тогда N7 отвергается без перебора правил.

Круг издержек: 2 × (комиссия + 8 б.п.):
- тейкер 0.10% — 0.36%;
- BNB 0.075% — 0.31%.

## 2. Окна (заморожено)

- **H:** 24 часа суток UTC. Держим с открытия часа h до его закрытия; доходность close/open по 1h, собранным из 15m.
- **D:** 7 дней недели UTC. Держим с 00:00 до 00:00 следующего дня.
- **S:** окна вокруг выплат фандинга, час до и час после 00/08/16 UTC: 6 окон, держим 1 час.
- Активы — BTCUSDT и ETHUSDT отдельно. Всего (24 + 7 + 6) × 2 = 74 окна.

## 3. Правило решения (заморожено)

- Для каждого окна — средняя валовая доходность за трейн и её 95% ДИ (бутстреп по дням).
- Если у всех 74 окон **средняя валовая доходность ≤ круга BNB 0.31%** → N7 **отвергнута границей**.
  Прочие правила не перебираются.
- Если хоть одно окно выше 0.31%, предрегистрация полноценной проверки пишется отдельно:
  отбор на трейне, тест на 2026 по решению оператора, поправка на 74 окна. Сама граница допуском не является.

Скрипт: `trader/_bound_seasonality_n7.py`. Читает только бары до 2026-01-01.

## 4. Результат (2026-10-28) — N7 ОТВЕРГНУТА: окно не отличимо от нуля, проверка невозможна по мощности

Граница §3 **не закрыла** гипотезу: 3 окна из 74 выше круга BNB 0.31% (`runtime/experiments/N7_BOUND.json`).

| окно | n | средняя валовая | 95% ДИ | ДИ с поправкой на 74 окна, нижняя граница | мощность теста 2026 (~43 дня) |
|------|---|-----------------|--------|-------------------------------------------|-------------------------------|
| ETH среда | 149 | +0.563% | [−0.022, +1.178] | −0.421% | 7% |
| BTC среда | 149 | +0.459% | [+0.033, +0.910] | −0.297% | 5% |
| BTC понедельник | 148 | +0.365% | [−0.125, +0.857] | −0.527% | 3% |

Для сравнения средний день трейна: BTC +0.161%, ETH +0.118% (бычий рынок).

**Отклонение от §3, раскрываю.** §3 предписывал при невыполненной границе писать полноценную проверку.
Я её не пишу, потому что она не может ничего решить:
- с поправкой на 74 окна ни одно окно не отличимо от нуля даже до издержек;
- если эффект трейна верен целиком, тест 2026 (~43 наблюдения) находит его с вероятностью 3–7%;
- для 80% мощности лучшему окну нужно ~1 700–2 700 таких дней, то есть 30–50 лет истории.

Поэтому N7 записана как отвергнутая: эффект не выделяется из множественного перебора, и проверить его на наших
данных нельзя. Повторять только при истории, в разы длиннее 2023–2025.
