## Исправление

`start_bot_detached.ps1` запускается через службу WMI (`Win32_Process.Create`),
поэтому у бота нет предка-Claude. Скрипт сам читает токен (файл runner или
`files\.env`) — токен не попадает ни в командную строку, ни в лог — и вызывает
`start_bot_bg.ps1`. Проверено: bot.py ← cmd-обёртка ← PowerShell от WMI (завершён).
