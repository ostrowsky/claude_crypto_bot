# E4: частичная фиксация прибыли (scale-out) поверх X4

Дата: 2026-11-18. Решение оператора: «какие гипотезы не были проверены? проверь их все по очереди». Трейдер (`trader/`). Спека
коммитится отдельно, до тестов, кода и любых чисел.

## 1. Вопрос

В плане трейдера (`autonomous-trading-roadmap-1010-spec.md` §4, этап E4) стоит «частичная фиксация прибыли; PARTIAL_25/8 отложен
06-01». В деньгах её никто не проверял. PARTIAL_25/8 из `_backtest_exit_policy_impulse.py` (июнь, только impulse_speed, без издержек)
закрывал половину позиции на +25%, а остаток вёл на трейле 8%.

**Гипотеза:** если закрыть половину позиции X4 лимитом на +X% от цены входа, а остаток вести тем же трейлом X4, дневная выручка
книги X4 станет выше.

Заранее: H4 (11-05) не нашёл умения во входах бота, X4 убыточен. Частичная фиксация меняет форму выплаты, а прибыль на входах без
умения создать не может. Поэтому вопрос — уменьшает ли она убыток, а не выводит ли в плюс.

## 2. Правило (заморожено)

- **База:** X4 = `experiment_x4f.BASE` (входы бота, P-1 трейл, пол 8%, 96 баров), та же модель исполнения (`fill_model.model("taker", 1)`),
  слоты и размер.
- **Новый вид выхода `p1_scale`** (`trading_policy.Exits`: `take_pct`, `take_frac = 0.5`):
  - сначала строится план X4 (бар и цена выхода раннера);
  - уровень `L = c0 · (1 + take_pct)`, где c0 — закрытие бара входа (та же опора, что у трейла);
  - на барах (ie, бар выхода X4] ищется первый, где максимум ≥ L · (1 + TP_TICK): цена прошла уровень, касание не считается;
  - если такой бар есть: сырая цена выхода = `take_frac · L + (1 − take_frac) · цена раннера`, бар выхода — бар раннера, причина `scale`;
  - если нет — план X4 без изменений.
- **Только 15m-сделки**, как у других новых выходов (h3 §2). 1h-сделки идут по X4.
- **Издержки** — те же, что на любом выходе (taker + проскальзывание), на всю сумму продажи. Для лимитной продажи это консервативно: на
  VIP0 maker = taker, а проскальзывания у лимита нет.
- **Раскрыто, не моделируется:**
  - слот и кэш закрытой половины освобождаются только с выходом раннера;
  - между фиксацией и выходом раннера дневная отметка считает всю позицию по рынку. Горизонт X4 — 96 баров (24 ч), так что затронута
    не больше одной дневной отметки на сделку. Итог сделки при этом точный.

## 3. Кандидаты (k ≤ 3)

| имя | take_pct | take_frac |
|---|---|---|
| S_t08 | 0.08 | 0.5 |
| S_t15 | 0.15 | 0.5 |
| S_t25 | 0.25 | 0.5 |

S_t25 — ближайший к PARTIAL_25/8 (раннер у X4 и так на трейле с полом 8%).

## 4. Окна и критерий

- **Train:** дни до 2026-07-01 (`experiment_x4f.SPLIT`), все сделки бота с начала журнала. **Test** — 2026-07-01.., открывается один раз,
  только по решению оператора. Окно 07..10 уже видел H3 (X4 там — база); это раскрывается, как в X4F.
- **Допуск кандидата на train** (как строка W в X4F):
  1. изменённых сделок ≥ 100 (`MIN_CHANGED`): другая цена выхода, чем у X4;
  2. парная дневная разность с X4: нижняя граница 95% > 0 (блочный бутстрэп, как в `DR.paired`).
- **Победитель** — наибольшее среднее парной разности среди допущенных. Нет допущенных — СТОП, test не открывается.
- **Если test откроют:** k = 1, α = 0.05; вердикт — `money_validator.improves` (парная разность, просадка, месяцы) и отдельно
  `profitable`. Прибыль самой книги на вердикт E4 не влияет: вопрос — улучшение X4.
- Отдельно записывается: сколько сделок дошло до каждого уровня, средний результат изменённых сделок против тех же сделок у X4,
  разложение по месяцам.

## 5. Тесты (до кода, `trader/test_scale_out.py`)

1. Эпоха политик без `take_pct` не меняется: X4 `0bccb4b2cf6d04f9`, чемпион `e196b96e7004b46b`.
2. Без пересечения уровня план `p1_scale` совпадает с планом X4.
3. С пересечением цена = `take_frac · L + (1 − take_frac) · цена раннера`, бар — раннера, причина `scale`.
4. Касание уровня без прохода (максимум = L) не даёт фиксации.
5. Пересечение после бара выхода X4 не учитывается.
6. 1h-сделка идёт по X4 без изменений.
7. Кандидаты: ровно три, с параметрами §3.
8. Ни одного допущенного — СТОП, маркер test не пишется; допуск требует и ≥ 100 изменённых, и нижней границы > 0.

## 6. Инварианты Truth Harness

TH-10, TH-11 (в деньгах, а не по захвату движения).
