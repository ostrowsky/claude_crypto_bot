## Контрфактуал

Для каждой реальной 15m-сделки: если монета не стала подтверждённым лидером (8
закрытых баров подряд в топ-3 дня при ≥ +7.5%) до реального выхода — результат
реальный. Иначе с первого такого бара — только широкий трейл движка П-1 (стоп
сбрасывается на close − max(k·ATR, F·close) и подтягивается), без WEAK/RSI/EMA/
выхода по времени, максимум 7 дней. Три варианта зафиксированы заранее.

## Вывод

Все три варианта проходят неухудшение и добавляют на ракетных днях +0.3…+0.8
п.п. к средней сделке, но **до цели не достают**: подтверждение лидера (2 ч) в
97.6% случаев наступает уже ПОСЛЕ того, как бот вышел. Узкое место — ранние
выходы до подтверждения, а не ширина стопа после него. Следующая гипотеза
должна переключать выход раньше — например, по более короткому подтверждению
(1 ч: 62% настоящих лидеров в `leader-mode-spec.md`) — и регистрироваться
заранее.
