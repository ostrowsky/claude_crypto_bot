# Сверка «демо против бумаги» в дневном отчёте трейдера (P2, G01/G04)

Дата: 2026-10-29. Решение оператора: «да, делай 2». Источник: GAP-отчёт соседнего приложения, пункты G01/G04, и наш
отчёт `reports/Аналоги ботов и RL в трейдинге.md`, где отсутствие ежедневной сверки «живое против бумажного» названо
пробелом. Только измерение: торговля, исполнитель и бумажная книга не меняются.

## 1. Зачем

Исполнитель торгует на демо-счёте сделки бумажной книги `exec_x4` (копия E7 `x4_floor8`). Любой будущий вывод о
деньгах на демо сравнивается с бэктестом и бумажной книгой. Без сверки нельзя сказать, откуда разница: исполнение,
комиссии, пропуски, срабатывание биржевого стопа. Тогда бэктест нельзя честно перенести на счёт (TH-11).

Сейчас посделочная разница уже считается ночью (`trade_dataset.live_vs_replay` → `runtime/learning/live_vs_replay.json`,
на 10-29: 53 демо-сделки, средняя +0.035 п.п.). Но в отчёт она не попадает, не разложена на причины и не считает
пропуски и расхождения.

## 2. Источник данных (только чтение)

Журнал решений `trader/runtime/audit/decisions/*.jsonl`, строки `book = exec_x4`, `mode = demo`:
- `real_entry` / `enter`: `key`, `cost`, `fill_price`, `paper_price` (цена сигнала), `slippage_bps`, `latency_sec`,
  `fee_usdt`, `fee_estimated`;
- `real_entry` / `skip`: `reason` (paused, asset_held, daily_loss_limit_real, exposure_cap, below_min_notional, ...);
- `real_exit` / `exit`: `pnl`, `ret_pct`, `reason` (time, trail, exchange_stop, ...), `paper_ret_pct`;
- `real_exit` / `skip` с `reason = already_closed`: `paper_ret_pct` сделки, закрытой раньше биржевым стопом;
- `real_exit` / `skip` с `reason = no_real_position`: бумажный выход без реальной позиции;
- `execution_divergence`: биржевой стоп сработал, бумага продолжает.

Строки `mode = paper` (этап C1 до 10-20) в сверку не входят.

## 3. Пара и разложение (заморожено)

**Пара** — один `key`: реальный вход `enter`, реальный выход и бумажная доходность `paper_ret_pct`. Последняя берётся
из строки `exit`, а если её нет — из строки `already_closed`. Пара полная, если есть все три.

Неполные пары считаются отдельно и не отбрасываются (TH-05):
- `open` — нет реального выхода;
- `no_paper` — есть реальный выход, но нет бумажной доходности (бумага ещё держит позицию).

**Разница сделки:** d = ret_pct − paper_ret_pct, в п.п. Деньги: gap_usdt = pnl − paper_ret_pct / 100 × cost.

**Разложение d** (в п.п., первый порядок). Модель бумаги — `fill_model.model("taker", 1)`: полспреда 8 б.п. на сторону
от цены сигнала, тейкер 0.10% на сторону. Слагаемые:
- вход = (8 − slippage_bps) / 100 — реальный вход относительно модельных 8 б.п.; плюс значит лучше модели;
- комиссии = 2 × (0.10 − 0.075) = +0.05, если комиссия входа оплачена BNB (`fee_usdt > 0` и не `fee_estimated`);
  иначе 0;
- выход и прочее = d − вход − комиссии: проскальзывание выхода против 8 б.п., задержка продажи, биржевой стоп.

## 4. Агрегаты

- **За день** (UTC-день реального выхода): число полных пар, средняя d, сумма gap_usdt, средние трёх слагаемых.
- **Вход** (UTC-день входа): среднее и медиана `slippage_bps`, 90-й процентиль, медиана `latency_sec`.
- **Покрытие дня:**
  - бумажных входов (все `real_entry`), из них исполнено и пропущено по причинам;
  - бумажных выходов без реальной позиции;
  - срабатываний биржевого стопа;
  - открытых и `no_paper`.
- **Окна 7 / 30 / всё.** Ряд по дням — средняя d за день. `daily_revenue.aggregate`, ДИ 95%. Направление
  («демо систематически хуже/лучше бумаги») называется только при ≥ 10 днях (`MIN_DAYS_DIRECTION`) и ДИ, не
  включающем 0; иначе — «рано судить».
- **Выбросы дня:** сделки с |d| > 1 п.п., не больше 5, по убыванию |d|.

## 5. Где показывается

Блок «6. Демо против бумаги» в `trader_report.py`, после блока 5. Расчёт делается из журнала решений при построении
отчёта, без нового файла состояния. Если демо-строк нет, блок пишет «нет демо-сделок».

## 6. Тесты (до кода, `trader/test_parity.py`)

1. Пара: enter + exit → полная, d и gap_usdt считаются. Exit без `paper_ret_pct`, но с более поздним `already_closed`
   → полная (биржевой стоп). Enter без exit → `open`. Exit без бумажной доходности → `no_paper`. Строки
   `mode = paper` и другие книги игнорируются.
2. Разложение: slippage 8 б.п. и BNB-комиссия → вход 0, комиссии +0.05, остаток = d − 0.05. Slippage 28 б.п. без BNB
   → вход −0.20, комиссии 0.
3. Покрытие: пропуски по причинам, `no_real_position`, `execution_divergence` считаются по дню.
4. Окна: меньше 10 дней → «рано судить»; ряд по дням — средняя d дня.
5. Блок отчёта: заголовок «6. Демо против бумаги», строки дня, окна, выбросы; без демо-строк — «нет демо-сделок».
