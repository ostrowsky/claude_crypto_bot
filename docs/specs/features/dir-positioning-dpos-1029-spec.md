# DPOS — добавляет ли позиционирование деривативов информацию к прогнозу 4h / 1d: предрегистрация

Дата: 2026-10-29. Решение оператора: «да, делай 2, потом спеку п. 1». Источник: GAP-отчёт соседнего приложения, лестница
данных «OHLCV → +market context → +derivatives» (§3.4), и наш DIR (`direction-forecast-dir-1029-spec.md`).
Офлайн, трейдер (`trader/`). **Загрузка архива — только после отдельного «да» оператора** (§3.3).

## 1. Вопрос

DIR показал: на признаках цены, объёма, BTC и рынка модель различает направление 4h / 1d слабо (AUC 0.517 / 0.529),
а купленный топ-дециль после издержек убыточен.

**Вопрос DPOS:** если к тем же признакам добавить позиционирование деривативов той же монеты (открытый интерес,
long/short, taker-ratio, фандинг), растёт ли AUC вне выборки и становится ли отбор лонгов прибыльным после издержек?

**Почему это не повтор:**
- E8 проверял позиционирование как фильтр входов бота на 60 днях, R-11 — для ракет на 60 днях. Оба результата —
  «рано судить» или отвергнуто.
- DPOS берёт позиционирование всего рынка за 3 года из публичного архива Binance, по тому же протоколу, что DIR.
- Единственная зацепка у нас: `oi_1h` указывал в одну сторону в обеих половинах теста лидеров (AUC 0.62–0.70),
  выборка мала.

**Литература** (`research_notes/Аналоги ботов и RL в трейдинге/data_signal_services.md`) не даёт доказательств, что
OI или long/short предсказывают доходность после издержек. Вероятный честный исход — «информации нет». Тест нужен,
чтобы закрыть эту ступень лестницы данных.

### 2.4. Проверка архива на пересчёт задним числом (PIT)
Архив публикуется после событий. Пересчитан ли он, проверяется на пересечении с живыми снимками бота, где оба
источника есть, — до 2025-12-31 его нет.

Поэтому проверка делается на одном отдельном отрезке 2026-08-21..2026-10-28:
- загружаются файлы метрик за эти дни для перпов из снимков бота;
- для каждого снимка `oi_1h` пересчитывается из архива на тот же момент;
- считаются Спирмен с `oi_1h` бота и медиана |разности| `top` / `retail`.

Критерий: Спирмен по `oi_1h` ≥ 0.9 и медиана |Δtop| / top ≤ 2%. Иначе архив не считается PIT и DPOS
останавливается.

Эти дни 2026 используются только для проверки данных. Прогноз, доходность и выбор модели на них не считаются.

## 4. Допуск (для каждого горизонта, α = 0.025 на два горизонта)

**Информация:** AUC(B) − AUC(A) на одних строках. Парный бутстрап по дням, блоки 5, 2000 повторов. Нижняя
граница > 0.

**Деньги:** B выполняет условия 2–4 DIR §6:
- топ-дециль после издержек, нижняя граница > 0;
- топ-дециль против вселенной, нижняя граница > 0;
- ≥ 2 из 3 лет ≥ 0.

**Исходы:**
- Оба условия выполнены → горизонт допускается к этапу 2: книга со слотами и случайным контролем, отдельная спека
  до любого взгляда на 2026.
- Выполнена только информация → «позиционирование несёт информацию, но не деньги». Результат записывается. Он
  разрешает отдельные предрегистрации на тех же данных: ракеты, лидеры, выходы.
- Не выполнено ничего → STOP, позиционирование для прогноза 4h / 1d повторно не проверять.

Тест 2026 открывается только решением оператора, один раз, маркер `DPOS_TEST_OPENED.json`.
