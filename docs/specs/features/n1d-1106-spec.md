# N1-D: carry с монетой в залоге, режим Multi-Assets (G3b)

Раздел дизайна: `n-family-experiment-designs-1105-spec.md` §3, N1-D (86dc8c9). Зависит от N1-B (`n1-1106-spec.md`): перенос на USDC не запрещён ни для BTC, ни для ETH. Коммитится до расчётов. Только история: демо не трогается, **Multi-Assets агент не включает**.

Инварианты: TH-03, TH-04, TH-05, TH-08, TH-10, TH-11, TH-12. Семейство N1, 2 кандидата, α = 0.025, уровень 97.5%.

## 1. Что фиксируется до данных
Правило, кандидаты, бенчмарк, окно и критерий — как в дизайне, без изменений. Ниже — что он оставил агенту.

**Издержки равны бенчмарку.** `carry.fees(1)`: спот 0.10% + 8 б.п., USDT-перп 0.05% + 8 б.п. на сторону. Это не сетка §1.4 по рангам (у BTC и ETH там ≈ 0), зато сравнение с FC_PASSIVE честное: разница не придёт из издержек. Оператор указал это в записке. Для G3b-USDC тейкер 0.04% + те же 8 б.п. Автообмен 0.10% + 10 б.п. по дизайну. Справочно та же книга при проскальзывании 0 и 20 б.п.

**Метки.** Закрытие первого 15m-бара дня, спот и перп на точном баре, как в G3a. День без точного бара пропускается и считается. Доход дня — изменение стоимости между метками, как в `coinm.run`.

**Стоимость.** E = U + Q_c · S + Q_s · (P₀ − P) · fx, где U — USDT-баланс, Q_c — монета в залоге, Q_s — шорт, fx = 1 для USDT-перпа.

**Фандинг.** Фактические начисления, которые читает FC (`funding_store`), для USDC — `runtime/usdc/`; номинал Q_s · (закрытие бара начисления). У USDC-перпа ставка и номинал в USDC пересчитываются по последней закрытой минуте USDCUSDT.

**Автообмен.** При U < 0 после начисления: продаётся столько монеты, чтобы U = 0 с учётом издержек. Шорт не меняется. Каждый случай записывается: время, USD, доля капитала.

**Запас маржи.** Отношение (0.95 · Q_c · S + U + Q_s · (P₀ − P) · fx) / (MMR · Q_s · P · fx), MMR = `carry.MMR` = 1%. Проверяется на каждой метке и на дневном максимуме перпа в этом дне при том же отношении S/P. Порог 3×.

**Дни.** Парная разность G3b − FC_PASSIVE на общих днях, `n_common.ci`, блок 20, уровень 97.5%, B = 20 000; блоки 5 и 60 для устойчивости.

**Окно.** USDT: 2023-03-01..2025-12-31. USDC: от 2024-02-02 (запуск + 30 дней по N1-B) до 2025-12-31, а FC_PASSIVE считается на тех же днях. В USDC-окно не входит кризис 2023-03, поэтому риск курса на нём занижен. Отдельно считается стресс: убыток при шоке fx из таблицы N1-C на всю книгу.

**Критерий — все условия, как в дизайне.** Нижняя граница > 0; разность > 0 минимум в 2 годах из 3 (для USDC из 2 лет — в обоих); ни одного автообмена > 1% капитала; запас ≥ 3× всё время.

**Мощность** на окне вперёд (не раньше 90 дней после коммита этой спеки): δ = 0.003 %/день, σ парной разности с этого окна, m = 20, ρ — автокорреляция лага 1, неотрицательная. Расчёт пишется в журнал. Если правило пройдёт, запланированный взгляд `G3B-F` вносится в журнал взглядов с α и датой. 2026 не открывается: прирост механический.

## 2. Тесты до кода
`trader/test_n1d_carry.py` — по списку дизайна:
- нейтральность: при нулевых фандинге и издержках стоимость не зависит от цены при ±50%;
- скидка залога меняет только запас маржи, но не P&L;
- автообмен срабатывает только при отрицательном USDT-балансе и платит заданные издержки;
- знак фандинга по шорту;
- сохранение денег: итог = старт + фандинг + курс − издержки;
- курс USDC/USDT и его вклад.
