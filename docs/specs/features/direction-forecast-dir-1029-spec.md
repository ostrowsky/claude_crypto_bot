# DIR — прогноз направления цены на 4h и 1d моделью с учителем: предрегистрация

Дата: 2026-10-29. Запрос оператора: «тестируй на старших таймфреймах 4h, 1d» — после отчёта
`reports/Аналоги ботов и RL в трейдинге.md`, где прогноз на 15 мин / 1 ч не окупает комиссии. Офлайн, трейдер
(`trader/`), бот не затрагивается.

## 1. Вопрос и почему он новый

**Вопрос:** может ли модель с учителем на признаках цены и объёма предсказать направление следующего 4-часового или
дневного бара достаточно хорошо, чтобы покупка отобранных ею пар на споте окупала издержки?

Порог безубыточности измерен на собственных барах (365 дней до 2026-10-29,
`research_notes/Аналоги ботов и RL в трейдинге/project_breakeven_measured.md`). Требуемая доля верных направлений
p* = 0.5 + c / (2m), где m — средний |log r| за горизонт, c — издержки круга:

| вселенная | горизонт | m, б.п. | p* спот 36 б.п. | p* спот 20 б.п. |
|---|---|---|---|---|
| 430 спотовых пар | 4h | 140 | 0.629 | 0.571 |
| 430 спотовых пар | 1d | 335 | 0.554 | 0.530 |
| BTC | 1d | 154 | 0.617 | 0.565 |

На 1d порог 0.53–0.56 попадает в диапазон, который литература называет достижимым (0.52–0.56). Отсюда тест.

**Что уже проверено и не перепроверяется.** Правила на тех же данных отвергнуты: моментум по ранжированию (XSMOM),
разворот (S1), тайминг BTC/ETH (TM), низкая волатильность (N8), многодневные удержания (MD), ротация BTC↔ETH (RV),
сезонность (N7). DIR отличается тем, что это **одна нелинейная модель** над многими признаками сразу. Если она выучит
лишь моментум или разворот, она провалится так же. Признаки календаря (час, день недели) не берутся: N7 их отверг.

## 2. Данные

- Бары: `trader/runtime/history/<PAIR>_15m.npz` (спот Binance, с 2023-01-01, включая делистинговые пары).
- Дневная панель: `experiment_xsmom.load_panel()` (673 пары).
- 4h-бары строятся из 15m: 16 баров; бар неполный, если баров меньше 16.
- **Вселенная** в момент решения дня d — `xsmom.universe(panel, d, cfg)`:
  - `cfg = Config(L=1, H=1, K=10, min_age_days=60)`;
  - 100 самых ликвидных пар по медиане квотируемого объёма за 30 дней до d;
  - без левереджных токенов, с возрастом пары не меньше 60 дней;
  - только строки < d.
- Для 4h берётся вселенная того же дня.

## 3. Строки, признаки, метка (заморожено)

**Момент решения:**
- **1d** — 00:00 UTC дня d. Вход по закрытию первого 15m-бара дня d (`first_close`), выход по `first_close` дня d+1.
- **4h** — закрытие 4h-бара k. Вход по закрытию первого 15m-бара блока k+1, выход по закрытию первого 15m-бара блока
  k+2.

**Метка.** y = 1, если r = выход / вход − 1 > 0. Нет цены выхода:
- если у пары нет ни одного бара в течение 3 дней после входа (делистинг), то r = −0.5 (`xsmom.DELIST_HAIRCUT`);
- иначе (пропуск в данных) строка отбрасывается.

**Признаки** (в барах своего горизонта, только бары ≤ момента решения):
- лог-доходности r1, r2, r3, r6, r12, r24;
- vol24 — std однобарных лог-доходностей за 24 бара;
- z1 = r1 / vol24;
- vq = log(квотируемый объём последнего бара / медиана за 24 бара);
- pos24 = положение закрытия в диапазоне закрытий за 24 бара;
- btc_r1, btc_r6 (BTCUSDT);
- mkt_r1, mkt_r6 — медиана по вселенной;
- xr1, xr6 — процентиль r1 и r6 внутри вселенной в этот момент;
- log_age — логарифм возраста пары в днях.

Итого 17 признаков. Нехватка истории — NaN, CatBoost так их и принимает.

## 4. Модель и деление по времени (заморожено)

- **Модель:** `CatBoostClassifier(depth=4, iterations=300, learning_rate=0.05, random_seed=29, loss=Logloss)`. Те же
  параметры, что в E2. Подбора гиперпараметров нет, иначе каждая настройка была бы ещё одной попыткой.
- **Окно трейна:** моменты решения 2023-03-01..2025-12-31.
- **Purged walk-forward** (`purged_cv.walk_forward`):
  - 4 фолда, дни делятся на 5 блоков, тестовые блоки 2–5;
  - эмбарго 2 дня;
  - модель фолда учится только на строках, чей исход известен до начала тестового блока минус эмбарго.
- **Предсказания вне выборки** собираются по тестовым блокам, примерно 2023-09..2025-12.
- **Окно 2026** не используется. Его открытие — решение оператора, k = 1, маркер `DIR_TEST_OPENED.json`.

## 5. Статистики (на трейне, для каждого горизонта отдельно)

Издержки c = 2 × (тейкер 0.10% + полспреда/проскальзывание 8 б.п.) = **36 б.п.** за круг, как `fill_model.model("taker", 1)`.

- **Отбор.** В каждый момент решения берутся пары с наибольшим p̂, floor(n / 10) штук, где n — размер вселенной.
  При равенстве p̂ — по имени. Если n < 10, отбора нет.
- **Издержки с учётом оборота.** Пара платит c/2 при входе, если её не было в отборе прошлого момента, и c/2 при
  выходе, если её нет в отборе следующего. Веса равные; ребалансировка весов внутри удержания не учитывается.
- **Дневной ряд.** Для каждого дня берётся среднее по моментам решения этого дня от
  `mean(r_отб) − издержки отобранных / число отобранных`, в %.
- **Парный ряд.** `mean(r_отб) − mean(r_вселенной)` в тот же момент; дневное среднее, в % (без издержек).
- **Отчёт рядом:**
  - AUC и точность вне выборки;
  - база (доля r > 0);
  - доля верных среди отобранных и p* для их среднего |r|;
  - BTC buy-and-hold и равновзвешенная вселенная за те же дни.

## 6. Допуск на трейне (все условия, α = 0.05 / 2 = 0.025 по двум горизонтам)

1. AUC вне выборки: нижняя граница 97.5% ДИ > 0.5. Бутстрап по дням, блоки 5, `seed 29`, 2000 повторов.
2. Дневной ряд отбора после издержек: нижняя граница ДИ `daily_revenue.aggregate(alpha=0.025)` > 0.
3. Парный ряд против вселенной: нижняя граница ДИ > 0.
4. Дневной ряд отбора ≥ 0 хотя бы в 2 из 3 лет (2023 — неполный, с сентября; 2024; 2025).

Все условия выполнены → горизонт допускается к этапу 2. Этап 2 — книга со слотами, случайным контролем с тем же
оборотом и сравнением с EW; он пишется отдельной спекой до любого взгляда на 2026. Ни один горизонт не допущен →
STOP, тест 2026 не открывается, результат коммитится.

## 7. Тесты (до кода, `trader/test_direction_dir.py`)

1. Признаки не видят будущего: замена баров после момента решения не меняет признаки.
2. Метка: вход и выход по `first_close` для 1d и по первому 15m-бару блоков k+1 / k+2 для 4h; делистинг → −0.5;
   пропуск → строки нет.
3. Отбор: floor(n / 10), равенство по имени, n < 10 → пусто.
4. Издержки с оборотом: пара в отборе три момента подряд платит c/2 один раз на входе и c/2 один раз на выходе.
5. AUC и ДИ: идеальный прогноз → AUC 1, нижняя граница > 0.5; случайный → ДИ содержит 0.5.
6. Walk-forward: в обучении фолда нет строк с исходом позже начала теста минус эмбарго.
7. Допуск §6 по всем четырём условиям; маркер теста ставится один раз; `test` без `--operator-approved` → 2.
