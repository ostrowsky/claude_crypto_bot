# RV — ротация капитала между BTC и ETH на споте: предрегистрация

Дата: 2026-10-28. Запрос оператора: проверить все спотовые гипотезы до шорта и фьючерсов. Офлайн.

## 1. Вопрос и отличие от проверенного

Весь капитал держится в одной из двух монет, BTC или ETH. Монета выбирается по их относительной доходности за N дней.

Чем это отличается от уже проверенного:
- **TM** решал «в рынке или в USDT» по каждой монете отдельно, здесь капитал всегда в рынке;
- **XSMOM и S1** выбирали из 100 альтов, здесь выбор из двух крупнейших монет и только между ними.

## 2. Правило (заморожено)

- **Решение** раз в сутки, в день d, по close строк < d. r_N(X) = close[d−1] / close[d−1−N] − 1.
- **Кандидаты (6)**:
  - `RV_mom_N` — держать монету с бо́льшим r_N;
  - `RV_rev_N` — держать монету с меньшим r_N;
  - N ∈ {14, 28, 56}.
  - При равенстве или без данных держится BTC.
- **Сделка** при смене монеты: продать всё по first_close дня d, купить другую по first_close.
  - Издержки `fill_model.model("taker", 1)` на каждой ноге.
  - Старт 1 000 000 USDT.
  - Отметка 00:00 по close d−1.
  - В конце окна последняя отметка, затем продажа.
- **Окна**: трейн 2023-03-01..2025-12-31 (панель обрезана до 2026). Тест 2026 открывается один раз и только по решению
  оператора, маркер `RV_TEST_OPENED.json`.

## 3. Сравнения

- **50/50** — половина капитала в BTC и половина в ETH, куплены в первый день и держатся без ребалансировки. Это основное
  сравнение: то же «всегда в рынке», без выбора.
- **Случайная ротация** — 50 сидов. Последовательность «какую монету держать» циклически сдвигается на случайное
  смещение в [30, n − 30]. Доля дней в ETH и число смен сохраняются.
- **BH BTC** и **BH ETH** — для справки.

## 4. Допуск на трейне (все условия)

1. mean R > p95 случайной ротации.
2. Парная разница с 50/50: mean > 0.
3. Годы: парная разница ≥ 0 хотя бы в 2 из 3 лет.
4. Смен монеты ≥ 12.

PBO (CSCV, 8 частей) по 6 кандидатам < 0.5. Победитель — допущенный кандидат с наибольшей парной разницей.
Нет победителя → STOP, тест не открывается.

**Тест** (k = 1, α = 0.05). Кандидат принят, если выполнены все три условия:
1. нижняя граница ДИ R > 0;
2. нижняя граница ДИ парной разницы с 50/50 > 0;
3. mean R > p95 случайной ротации.

## 5. Тесты (до кода, `trader/test_rotation_rv.py`)

1. Выбор дня d не видит строк ≥ d.
2. Без издержек:
   - постоянное «ETH» воспроизводит отношение цен ETH;
   - смена монеты в день d переносит весь капитал по first_close.
3. Сохранение денег; после окна позиций нет.
4. Сдвиг сохраняет долю ETH и число смен.
5. 6 кандидатов; допуск по §4.
