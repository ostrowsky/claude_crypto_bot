# RB — периодическая ребалансировка BTC / ETH / USDT против удержания тех же весов: предрегистрация

Дата: 2026-10-29. Решение оператора: «все» (пункт 3 списка после EX-RL1). Источник: GAP-отчёт соседнего приложения
(Binance Rebalancing bot) и наш отчёт `reports/Аналоги ботов и RL в трейдинге.md`. Офлайн, трейдер (`trader/`).

## 1. Вопрос и ожидание

**Вопрос:** даёт ли периодическая ребалансировка к постоянным весам прибавку к удержанию тех же начальных весов без
ребалансировки, после издержек?

Чем RB отличается от проверенного:
- RV выбирал одну монету из двух, а не держал фиксированные веса;
- TM переключал «в рынке / в USDT» по сигналу.

**Ожидание по теории, записано заранее.** Прибавка ребалансировки до издержек ≈ ½ · w(1 − w) · дисперсия разности
доходностей:
- около +0.006 %/день для BTC/ETH при корреляции ~0.85;
- около +0.011 %/день для 50/50 с USDT.

Издержки ежедневной ребалансировки, вероятно, съедят это целиком, у еженедельной шансы выше.

**Оговорка.** Это не рыночно-нейтральный доход, как FC. RB несёт рыночный риск своих весов, и абсолютный R
публикуется рядом.

## 2. Данные и правило (заморожено)

- **Цены.** Дневная панель `experiment_xsmom.load_panel()`, BTCUSDT и ETHUSDT. Сделки и отметки идут по `first_close`
  дня, то есть по закрытию первого 15m-бара UTC-дня.
- **Кандидаты (6).**
  - Веса: BTC/ETH 50/50; BTC/USDT 50/50; ETH/USDT 50/50.
  - Период ребалансировки: каждый день или каждые 7 дней.
- **Ребалансировка.** В день ребалансировки продать то, что выше цели, затем купить то, что ниже.
- **Издержки** — `fill_model.model("taker", 1)`: тейкер 0.10 % + 8 б.п. на сторону. Капитал 1 000 000 USDT. Ордера
  меньше 10 USDT не исполняются.
- **Бенчмарк.** Те же начальные веса без ребалансировки (BH той же смеси).
- **Окна.**
  - Трейн: 2023-03-01..2025-12-31 (панель обрезана до 2026).
  - Тест 2026: один раз, только решением оператора, маркер `RB_TEST_OPENED.json`.

## 3. Допуск на трейне (все условия, α = 0.05 / 6)

1. Парная разница RB − BH той же смеси по дням: нижняя граница ДИ (1 − α) > 0.
2. Парная разница ≥ 0 хотя бы в 2 из 3 лет.
3. PBO по 6 кандидатам < 0.5.

Победитель — допущенный кандидат с наибольшей парной разницей. Нет победителя → STOP.

Тест 2026, если он будет открыт:
- нижняя граница парной разницы > 0;
- абсолютный R публикуется рядом, но решения не меняет.

## 4. Тесты (до кода, `trader/test_rebalance_rb.py`)

1. Без издержек и без ребалансировки RB = BH: капитал равен сумме долей × относительная цена.
2. При постоянных ценах ребалансировка ничего не меняет, кроме издержек на нулевой оборот (ноль).
3. Расписание: ребалансировка в день 0 (покупка) и далее каждые k дней.
4. Издержки: оборот × (0.10 % + 8 б.п.) на сторону.
5. Сохранение денег: итог = кэш + позиции по последней отметке.
6. Нога USDT держится как кэш без издержек.
7. Допуск §3 и маркер теста (один раз); `test` без `--operator-approved` → 2.
