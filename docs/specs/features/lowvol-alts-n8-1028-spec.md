# N8 — корзина спот-альтов с самой низкой волатильностью: одно правило, один взгляд на 2026, предрегистрация

Дата: 2026-10-28. Источник: `trader-hypotheses-1028-spec.md`, N8. Решение оператора 2026-10-28: сначала все
гипотезы для спота, N8 — «пробуй».

## 1. Почему одно правило и сразу тест

Идея пришла из трейна. XSMOM и S1 на 2023–2025 показали, что обе крайности прошлой доходности проигрывают
случайным портфелям; возможная причина — волатильность. Трейн для N8 поэтому не чистый: выбирать на нём
параметры значило бы подгонять под уже виденное. Правило фиксируется **до** взгляда, без сетки, и судится один раз
на 2026 году. Для рейтинга альтов окно 2026 не открывалось (`xsmom-daily-money-1021-spec.md`,
`s1-reversal-universe-1021-spec.md`). Трейн считается в том же прогоне только для справки и на решение не влияет.

## 2. Правило (заморожено)

- **Универсум**: `xsmom.universe` — 100 самых ликвидных спот-пар по медиане оборота за 30 дней. Без стейблкоинов
  и токенов с плечом. Пара старше 60 дней (`min_age_days = 60`, как S1).
- **Оценка** пары в день d: σ̂ — стандартное отклонение дневных лог-доходностей close за 28 дней до d (28 доходностей,
  все дни полные). Без полных 28 доходностей пара не оценивается.
- **Выбор**: K = 10 пар с наименьшей σ̂, при равенстве — по имени.
- **Ротация**: как XSMOM H = 7. Семь траншей по 1/7, транш i обновляется в день (d − старт) % 7 == i. Продаются только
  выпавшие пары, освободившиеся деньги делятся поровну между новыми.
- **Деньги**: `xsmom.rotate`, исполнение по first_close, `fill_model.model("taker", 1)`, старт 1 000 000 USDT,
  делистинг со скидкой 50%.

## 3. Окна

- **Тест**: решения 2026-01-01 .. последний полный день панели `xsmom_panel.npz`. Открывается один раз, маркер
  `N8_TEST_OPENED.json`, k = 1, α = 0.05.
- **Справка**: трейн 2023-03-01 .. 2025-12-31 тем же кодом, в отчёте рядом, без влияния на вердикт.

## 4. Сравнения

- **EW** — равновзвешенный универсум с той же ротацией H = 7 (`xsmom.ewu_chooser`). Это основное сравнение.
- **Случайный выбор** — 50 сидов с тем же оборотом (`xsmom.matched_random`).
- **BTC «купи и держи»** (`xsmom.btc_chooser`) — для справки.

## 5. Решение (заморожено)

**ПРИНЯТО**, если выполнены все три условия:
1. R теста: нижняя граница 95% ДИ > 0;
2. парная разница с EW: нижняя граница 95% ДИ > 0;
3. mean R > p95 случайного выбора.

Иначе — отвергнуто. Принятие означает теневую книгу, не деньги.

## 6. Тесты (до кода, `trader/test_lowvol_n8.py`)

1. σ̂ дня d не видит строк ≥ d.
2. Выбираются K пар с наименьшей σ̂; равенство решается по имени; пара без 28 полных доходностей не оценивается.
3. Вызов через `xsmom.rotate` держит ровно выбранные пары: на синтетике у спокойных пар позиции есть, у шумных нет.
4. Тест открывается один раз: второй запуск — ошибка; запуск без `--operator-approved` не идёт.
5. Решение по §5 на синтетических числах.

## 7. Результат (2026-10-28) — N8 ОТВЕРГНУТА на единственном взгляде на 2026

Как проверено:

- маркер `N8_TEST_OPENED.json` поставлен до расчёта;
- запись в `trials.jsonl`, k = 1;

Что это значит:
- На трейне корзина обгоняла и рынок (точечно +0.06 %/день), и случайный выбор. Это то самое наблюдение, из которого
  выросла идея.
- На 2026 году она хуже рынка и далеко ниже случайного выбора. Наблюдение трейна не переносится.
- «Спокойные» альты 2026 года — это крупные монеты, падавшие вместе с рынком.

N8 закрыта. Повторно не проверять наклон к низкой волатильности на этом универсуме.
