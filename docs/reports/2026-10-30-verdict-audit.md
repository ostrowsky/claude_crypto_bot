# Аудит вердиктов гипотез трейдера: где «отвергнута» сказано без достаточных оснований (2026-10-30)

Запрос оператора: «найди ошибки в проверке гипотез, которые привели к неверным выводам». Ниже два систематических
дефекта протокола трейдера, проверенные по системе. Третий отмечен как непроверенный.

## Дефект 1. Нарушено правило «максимальный период»: трейн шёл на 3 годах из 6–8 доступных

Проверено 2026-10-30:
- `history_store.SINCE_DEFAULT = "2023-01-01"`, `funding_store.SINCE_DEFAULT = "2023-01-01"`;
- дневная панель `experiment_xsmom.load_panel()` — 2023-01-01..2026-10-22, 673 пары.

Публичный архив `data.binance.vision`, проверено чтением индекса:

| ряд | первый файл |
|---|---|
| спот BTCUSDT, ETHUSDT, 1d | 2017-08 |
| спот LINKUSDT, 1d (пример альта) | 2019-01 |
| USD-M BTCUSDT, свечи и фандинг | 2020-01 |

**Следствия:**
- Гипотезы, проверенные только на ценах (XSMOM, S1, TM, N7, N8, MD-U, RV, RB, DIR, SN, FC), видели один рыночный режим:
  альты 2023–2025 упали на 51% к BTC. Режимы 2020–2021 (широкий рост альтов) и 2022 (обвал) не проверены ни одной
  гипотезой.
- 2019–2022 ни одна гипотеза не видела. Это **свежий отложенный период «назад во времени»**: замороженное правило из
  каждой спеки можно проверить на нём без открытия окна 2026.
- Для FC это критично: 2021 — эпоха высокого фандинга. Оценка ~4 %/год на трейне 2023–2025 и падение в 2025 — оценка
  по одному режиму.

## Дефект 2. «Отвергнута, повторно не проверять» там, где ДИ включает экономически значимый плюс

Правило TH-10 запрещает выводы, которых данные не поддерживают. «Нижняя граница ДИ < 0» значит «не доказано», а не
«опровергнуто». Опровержение — это верхняя граница ниже значимого эффекта. Числа взяты из журналов спек:

| гипотеза | ключевая величина | ДИ | как записано | честное прочтение |
|---|---|---|---|---|
| DIR 4h, топ-дециль после издержек | −0.195 %/период | [−0.254, −0.136] | отвергнута | **опровергнута** (верх < 0) |
| DIR 1d, топ-дециль после издержек | −0.257 %/день | [−0.598, +0.061] | отвергнута, не проверять | **не доказана**: верх +0.06 %/день ≈ 22 %/год |
| DIR 1d, против вселенной | −0.007 | [−0.138, +0.121] | — | **не доказана** |
| DPOS 4h, ΔAUC | −0.0056 | [−0.0094, −0.0015] | отвергнута | **опровергнута** |
| DPOS 1d, ΔAUC | −0.0035 | [−0.0153, +0.0082] | отвергнута, не проверять | **не доказана** |
| TM, лучший против постоянной экспозиции | +0.027 | [−0.039, +0.093] | отвергнута | **не доказана**; на 2017–2022 не проверялась |
| N8 (окно 2026, один взгляд) | −0.065 | [−0.261, +0.088] | отвергнута | **не доказана** |
| RV (окно 2026, один взгляд) | +0.0066 | [−0.318, +0.294] | отвергнута | **неинформативна** (ширина ±0.3 %/день) |
| SN, лучший | +0.098 | [−0.098, +0.296] | отвергнута | доходность **не доказана**; отказ по ликвидациям (> 5%) обоснован |
| XSMOM, лучший против EW | +0.016 | [−0.114, +0.151] | отвергнута | против EW не доказана; отказ обоснован случайным контролем (хуже ≥ 88% случайных в 9 из 12) |
| RB, лучший против удержания | +0.0033 | [−0.024, +0.039] | отвергнута | ДИ широк, но теория ограничивает эффект ~0.006 %/день: **практически ничтожна** |
| QB_T0 (окно 2026) | +0.0004 | [−0.0039, +0.0046] | отвергнута | **опровергнута** относительно FC (верх ~1.7 %/год) |
| EX-RL1 A1 | −3.7 б.п. | [−5.0, −2.7] | отвергнута | **опровергнута** |

**Мощность** (оценка по DIR 1d): стандартное отклонение дневного ряда ≈ 1.6 %, 828 дней.
- Стандартная ошибка ≈ 0.056 %/день, минимально обнаружимый эффект ≈ 0.11 %/день (≈ 40 %/год).
- Эффект в 10–20 %/год такой тест не различает в принципе.
- На 2019–2025 (≈ 2 480 дней) порог снизится до ≈ 0.065 %/день.

## Дефект 3 (не проверен, на вывод, вероятно, не влияет). Издержки 8 б.п. на сторону для всех пар

Сверка «демо против бумаги»: медиана проскальзывания входа 0 б.п., среднее +7.8. Спред ETH в замере EX-RL1 — 0.04 б.п.
Для ликвидных пар модель, возможно, переплачивает ~5 б.п. на сторону, плюс BNB-скидка 2.5 б.п. на сторону.

Пересчёт «в уме» для самых оборотных тестов:
- DIR 4h: валовой ≈ +0.012 %/период при издержках 0.207 → с издержками ~0.10 итог ≈ −0.09, всё ещё < 0;
- X4: валовой ≈ −0.145 %/сделку.

Знак, по-видимому, не меняется, но это не проверено по каждой гипотезе.

## Что из этого следует

1. Поправить формулировки в спеках, CLAUDE.md и PROJECT_CONTEXT.md: «не доказана при мощности …» вместо
   «отвергнута, не проверять» для строк с пометкой **не доказана**.
2. Загрузить спотовую историю 2019–2022 (свечи с data.binance.vision для пар панели, включая делистинговые) и фандинг
   2020–2022. Это требует разрешения оператора.
3. Проверить **замороженные правила** не доказанных гипотез (DIR 1d, TM, N8, DPOS 1d) и FC_PASSIVE на 2019–2022 как на
   отложенном периоде. Без подбора параметров, k по числу правил.
